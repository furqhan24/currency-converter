# Currency Converter

A real-time currency conversion web application developed using HTML, CSS, and JavaScript. The application retrieves live exchange rates through an external currency API and dynamically converts values between different currencies.

## Features

* Real-time currency conversion
* Live exchange-rate retrieval using API integration
* Dynamic currency selection
* Automatic country flag updates
* Input validation
* Responsive user interface
* Fast and accurate conversion results

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* JSON
* Exchange Rate API

## How It Works

1. Users select source and target currencies.
2. The application sends an API request to retrieve the latest exchange rates.
3. JSON data is processed and the appropriate conversion rate is extracted.
4. The converted amount is calculated and displayed instantly.
5. Country flags are updated dynamically based on the selected currencies.
